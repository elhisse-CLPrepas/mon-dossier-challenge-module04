## Exécuter réellement Python

Depuis la racine `mon-dossier-challenge-module04` :

```powershell
python 06-ressources/demo/demonstration-s13.py
```

Ou, sous Windows, remplacer `python` par `py -3`. Le script affiche les résultats sans écrire de fichier. Pour observer cellule par cellule, ouvrir `demonstration-s13.ipynb` dans VS Code ou Jupyter avec un noyau Python 3 et exécuter dans l’ordre. Sans environnement Python, consulter `sorties-observees.md` et noter « sorties préparées consultées ».
